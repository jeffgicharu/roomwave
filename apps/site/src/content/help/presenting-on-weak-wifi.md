Most halls are not built for four hundred phones. Roomwave is designed for that:

- **The page is small.** The page a phone opens to answer is a fraction of the size of a typical website, so it opens quickly even on a weak mobile signal.
- **It reconnects by itself.** If a phone loses its connection, it reconnects and catches up with the current slide. People do not need to scan again.
- **It finds a way through.** Some venue networks block the live connections Roomwave prefers. When that happens it switches to ordinary web requests automatically. Answers arrive a moment later, but they arrive.
- **Nobody is counted twice.** A phone that reconnects is the same person, with the same answers.

## What helps

- **Tell people mobile data is fine.** Roomwave uses very little, so they do not need the venue's Wi-Fi.
- **Show the code for longer.** Press **Q** at the start so the code and QR fill the screen while people join.
- **Close answers before revealing.** On a slow network, give it a few seconds before you close a question, so the last answers land.
- **Test the room.** Join from your own phone over the venue's network before people arrive.
